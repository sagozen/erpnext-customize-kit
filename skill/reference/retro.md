# retro: Capture implementation lessons and support improvements

Stage: **Ship**. Invoked as `{{command_prefix}}pankit retro`.

## When this runs

Capture implementation lessons and support improvements when requested or needed to complete authorized ERPNext work.

## Read first

Read plan, actual effort, feedback, incidents, support requests and decisions. Separate measured evidence from recollection.

## Steps

1. Compare requirements with delivered behavior, setup friction, escaped defects and operator questions.
2. Identify which standard choices saved work and which customizations caused maintenance cost. Record context rather than inventing universal rules.
3. Separate customer policy, reusable industry knowledge and framework guidance. Update only the owning reference when evidence supports it.
4. Assign follow-up owner, priority and observable outcome. Account for the solo founder's support/upgrade time.
5. Keep dated history separate from current authority. Redact private data and credentials.

## What this produces

Dated retrospective and evidence-backed guidance changes.

## Handoff

Feed unresolved needs into the next spec; do not expand implementation silently.
